# 1.3.0-rc1 全局 Widevine TEE 后端离线候选报告

日期：2026-08-23

## 产品结论

本候选不使用应用包名、UID/EUID、PID 或 TGID 划分作用域。Binder 与
OEMCrypto/SMCInvoke TEE 直连后端共享同一个 mode、seed/profile、配置 generation
和 32 字节虚拟 DRM ID；调用者变化不轮换 ID。

“全局”表示所有已识别 Widevine 调用者均生效，不表示覆盖所有 Trusted App。
`op9 + [OB] + 32 bytes` 也存在于 qms，故仍保留 Widevine TA 对象身份校验：

```text
widevine.mbn size + prefix32 + suffix32
  -> loader op0 [IB,OO]
  -> controller op2 [OO]
  -> Widevine TA object
  -> op9 [OB] / result=0 / size=32
```

已缓存 loader 使用实机确认的连续签名：

```text
op16 [IB,OB]
-> op0 [IB,OB]
-> op19 [IB,IB,IB,OB]
-> op20 [IB,OB,OB,OB]
-> op9 [OB]
```

## 实现状态

- 版本：`1.3.0-rc1`；
- Kernel Context ABI：19；
- Runtime control：`DRMCTL18` / v3 / 128 bytes（配置布局未变）；
- Control IPC：`DRMIPC19` / v4 / 352 bytes；
- Control socket：`drmid_control_v4.sock`；
- TEE Hook：导出符号 `si_object_do_invoke` 与 `free_si_object`；
- 已验证 6.12 profile：`paciasp/sub sp,#0xd0/...` 与
  `paciasp/stp x29,x30/...`；
- 固件路径按固定顺序发现，普通文件 + `O_NOFOLLOW` + 64 B–16 MiB边界；
- controller 16 项、TA 32 项、fallback 16 项；
- 对象表采用严格有界 LSE CAS，热路径无动态分配、无阻塞锁、无日志；
- `free_si_object` 按对象指针清除三张表，避免地址复用；
- 安装失败回滚 TEE invoke Hook，卸载按 free→invoke→Binder 逆序执行；
- TEE profile缺失时保持 Binder 后端运行。
